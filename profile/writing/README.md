# Writing samples

Drop a few things **you** wrote here as `.md` or `.txt` (a motivation letter, a blog post, a cover letter you were proud of).
Chotu uses them as style references so outreach emails and cover letters sound like you, not like an LLM.

PDFs are not uploaded by `npm run sync-profile`, so paste the text into a `.md` file.
Keep personal samples out of a public fork. The `.gitignore` ignores everything in this folder except this README.
